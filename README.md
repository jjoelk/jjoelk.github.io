# Jeremyah Joel

Personal portfolio for application security, cloud detection, and AI research.
Published at https://jjoelk.github.io/ through GitHub Pages from the root of `main`.

The site uses plain HTML, CSS, and JavaScript, with no build step or third-party runtime dependencies.

## Local preview

Run `python3 -m http.server 4173` from this directory, then open http://localhost:4173/.

## Files

- `index.html`: biography, selected work, experience, and writing.
- `styles.css`: responsive layout, keyboard focus, reduced motion, and print styles.
- `script.js`: accessible harness-stage tabs and navigation highlighting.
- `assets/Jeremyah-Joel-CV.pdf`: current public CV.

## Content

Project descriptions link to the published research. Preserve the distinction between reported and accepted findings, the date of the research summary, and the scope of the SHADOW benchmark: one warm, single-threaded domain lookup. VigilX is a side project, and incident-response experience is described as support.

Push updates to `main` to publish through the existing GitHub Pages configuration.
