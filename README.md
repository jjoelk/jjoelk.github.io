# Jeremyah Joel

Personal page for Jeremyah Joel's security research, AI engineering, and work as a founding engineer, published at https://jjoelk.github.io/ through GitHub Pages from the root of `main`.

The page uses HTML and CSS with no build step, JavaScript, or third-party runtime dependencies.

## Local preview

Run `python3 -m http.server 4173` from this directory, then open http://localhost:4173/.

## Structure

The page introduces Jeremyah as a security researcher and founding engineer, then presents three illustrated stories about his work and its results, with their article links. A wider research summary and two additional pieces of writing follow, ending with links to public profiles. Warm paper, forest green, serif display type, and original vector artwork give the page its visual identity.

- `index.html`: introduction, research notes, writing, and public profile links.
- `styles.css`: responsive typography, layout, keyboard focus, reduced motion, and print styles.
- `assets/art/`: original decorative SVG illustrations. The adjacent copy carries the meaning and evidence; artwork is hidden from assistive technology.
