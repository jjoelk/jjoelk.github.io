# Jeremyah Joel

Personal research journal, published at https://jjoelk.github.io/ through GitHub Pages from the root of `main`.

The page uses HTML and CSS with no build step, JavaScript, or third-party runtime dependencies.

## Local preview

Run `python3 -m http.server 4173` from this directory, then open http://localhost:4173/.

## Structure

The page introduces Jeremyah's small lab, then presents three illustrated research notes with their article links. Two additional pieces of writing follow, ending with links to public profiles. Warm paper, forest green, serif display type, and original vector artwork give the page its visual identity.

- `index.html`: introduction, research notes, writing, and public profile links.
- `styles.css`: responsive typography, layout, keyboard focus, reduced motion, and print styles.
- `assets/art/`: original decorative SVG illustrations. The adjacent copy carries the meaning and evidence; artwork is hidden from assistive technology.

## Content

Keep each project and its article together. Write about the questions, decisions, and limitations behind the research. Preserve the SHADOW benchmark's scope: one warm, single-threaded domain lookup. VigilX is a side project. Do not publish CVs, direct personal contact details, employment chronology, education, or credential lists on this page.

Push updates to `main` to publish through the existing GitHub Pages configuration.
