SHADOW — searching exposed login records

The challenge was making 4.19 billion canonical credential records (records of exposed login details) searchable on a 16 GB Mac Mini. I built indexes in advance so a website-domain lookup doesn’t need to scan the whole collection. One measured warm, single-threaded domain lookup took 0.38 seconds.

Precompute, Don’t Search ↗July 2026

Google Cloud Armor — following an unexplained bypass

At GovTech Edu, some web requests got past Cloud Armor’s protection, but the logged details didn’t explain why. I spent months investigating with the team and helped produce a reproducible report. Google confirmed the issue affecting Classic Application Load Balancers and released a global patch.

Read the Cloud Armor investigation ↗November 2024
